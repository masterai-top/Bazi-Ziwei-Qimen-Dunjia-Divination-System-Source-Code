Public Scope

The repository contains HTML and JavaScript pages, Java service interface examples, and product screenshots for Bazi chart and Chinese metaphysics software research.

This is not a complete Spring Boot, Docker, or commercial SaaS distribution. Complete Ziwei Doushu and Qimen Dunjia algorithm coverage must be verified from source and reproducible tests.
