# Contributing

Contributions should keep the repository safe for public review and commercial communication.

## Guidelines

- Do not commit production secrets, user data, payment keys, private prompts, or private customer reports.
- Keep examples desensitized and easy to run.
- Document calculation assumptions when adding Bazi, Ziwei, Qimen, naming, or fortune report logic.
- Add tests for chart calculation, date conversion, API output, and report-generation changes.
