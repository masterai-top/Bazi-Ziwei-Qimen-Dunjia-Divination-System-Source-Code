## Unique Advantages

This project is a comprehensive calculation system that integrates traditional Chinese metaphysics methods such as Bazi, Ziwei Doushu, and Qimen Dunjia. It uses a Java backend and a web frontend to provide an extensible implementation for research and application development.

| Module | Description |
| :--- | :--- |
| **Four Pillars of Bazi** | Yin-Yang and Five Elements, Heavenly Stems and Earthly Branches, chart generation, and fortune calculations |
| **Ziwei Doushu** | Star chart generation, fortune analysis, and auxiliary-star interpretation |
| **Qimen Dunjia** | Chart generation, pattern analysis, and auspicious or inauspicious assessment |
| **Qizheng Siyu** | Traditional astronomical calendar calculations and celestial-body movement analysis |
| **Da Liu Ren** | Liu Ren divination charts and event interpretation |
| **Clash and Combination Analysis** | Earthly Branch punishments, clashes, combinations, harms, and auxiliary-star analysis |
